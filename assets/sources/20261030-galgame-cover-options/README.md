## 设计依据

使用内置 `image_gen.imagegen`，五个方案分别生成。以本工程已采用的角色及场景图为视觉参考，转译为Galgame封面插画；来源文件未改动，参考图指纹与当前采用清单一致。

商业视觉小说的设计研究入口为[《ハミダシクリエイティブ》官网](https://madosoft.net/hamidashi/)与[《喫茶ステラと死神の蝶》官网](https://www.yuzu-soft.com/products/stella/)。本批仅借鉴群像层次、人物近景、标题Logo和留白等设计方法，不复制商业游戏原画、人物或标志；具体五个方向为本批原创设计判断。

A/C/D是四位常规女主的封面蒙太奇，不代表多路线剧情同时发生；B为飘，E为黄球球。未加入叶岚攻略身份、额外剧情设定或其他宣传文字。E只画黄球球门内半身，不扩展未显示下装，不解释眼部遮片，不把玩偶棒赋予功能。
