## 性格与独立目标

文文回到毕节，先在网吧做夜班网管。他能接玩笑，也习惯把不顺讲成一件小事；别人问以后打算，他容易用“先做着”结束话题。他真正难以面对的，是自己暂时没有一个拿得出手的答案，却又不想被熟人看出在意。

他想靠这份工作把生活安顿下来，攒出能自己支配的钱，再决定下一步。工作不是等待恋爱来拯救的空档；选择留下、换工作或继续探索，都应由他的实际经历推动。成长体现在敢说“我还没想好”，也愿意为已经答应的事安排时间。

## 三层差异

| 层次 | 表现 |
| --- | --- |
| 别人眼中 | 随和、会接梗，谈到夜班和返乡总能自嘲两句，看起来没什么大不了 |
| 熟悉之后 | 很在意别人怎样看待自己的现状；游戏里爱逞强，生活中也容易把“不会”和“累了”咽回去 |
| 关系靠近 | 愿意说明自己的作息、能力与难处，主动约下一次相见，也能接受别人照顾；仍会开玩笑，但不再靠玩笑避开回答 |

## 工作与相处边界

- 日常工作是接待、收银、补货和处理座位使用等基础事务；超出能力的问题交给师匠安排，不设为精通各种设备的维修高手。
- 当班先履行网管职责。游戏只发生在明确的休息时间或下班后，不把上班挂机、忽视顾客写成日常。
- 开篇值22:00—次日06:00夜班；工作与排班变化按所选路线正文，不把朋友线网吧转手套到其他路线。
- 相处来自约饭、顺路同行、朋友聚会、游戏与主动邀约。文文也会缺席、拒绝和犯错；女主可以主动找他、帮他，或只是想和他待一会儿。
- 不把每段关系都写成“别人出了问题，文文赶去解决”。游戏输赢能显出性格，但不替代现实中的沟通，也不把恋爱变成奖励。
