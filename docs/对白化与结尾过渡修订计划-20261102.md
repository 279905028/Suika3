## 一、先统一改写和演出规则

1. **按场景功能改写。** 优先把转述的争执、问答、解释、商量和关系确认写成实际对白；每句至少推动行动、揭示人物或改变关系。不把心理活动强行说出口，不把财务背景写成双方都知道的长篇问答。
2. **保持人物口吻。** 从当前人物资料与原稿提炼各人的用词、回避方式和说话节奏；保留自然口语与少量原有地方表达，减少总结道理式台词。对白占比只作前后比较，不设凑字数指标。
3. **一条对白只对应一位说话人。** 动作与台词分开；当面、电话、视频、语音、文字消息、心声分别记录。正式字段和源稿语法先通过小样验证，再铺到全稿。
4. **名字与立绘分别判断。** 文文开口显示“文文”；其他人显示当前已知姓名，尚未揭示身份者显示“门内的声音”等已有称呼，普通配角用“司机”等身份，不补造名字。消息注明发送者，远程发言不自动变成现场人物。
5. **姓名框完整清理。** 旁白、纯动作、选择提示和结束页不残留上一人的名字；同一句跨页保持姓名，换人立即切换；明确写出的心声与实际发言区分。回顾、自动播放、快进、存读档和回退沿用相同信息。
6. **稳定演出锚点。** 为新增或重组的关键场景/台词组设置稳定标识；记录原段落到新段落的一对多映射。兼容既有NODE、选择、结局与条件标记，不以行号或模糊文本搜索作为最终绑定依据。

先选三个技术小样：第一章网吧多人交流、飘LOW关系确认、孟遥AA/BA条件片段。小样只用于验证格式与显示链路，不引入新设定，也不单独替换正式候选。

## 三、十四结局的过渡方向

每个结局检查三个环节：**决定有来由 → 双方实际回应 → 新状态落到生活**。2—3段短场景可利用已有车站、通话、饭桌、门口和下班场景，不要求增加新日期或新地点。

| 路径 | 继续/靠近的结局 | 分开/疏远的结局 |
| --- | --- | --- |
| 罗小满 | 从车站决定接到异地沟通与现实安排，把转述变成问答 | 保留AB/BA/BB不同经历，作品与普通互助不变成复合暗示 |
| 周栀 | 把职业现实、双方不适与具体约定接稳，补普通相处的回应 | 加强第八章告别及第九章适应；不为增加台词让她主动重新暧昧 |
| 孟遥 | 写清受课表、婚姻和费用限制的秘密往来，不包装成公开复合 | 分清最终收尾联系与恢复亲密，按AB/BA/BB保留不同过程，终止私人联系 |
| 飘HIGH | 修订资料交接与远程媒介，展示异地关系怎样继续 | 从归还资料过渡到各自生活，不以册子反复制造联系 |
| 飘LOW | 重点扩写再次了解、双方愿意试交往、实际相处与边界 | 将拒绝继续追求、对方回应、作为朋友的相处写完整，不用旁白一句带过 |
| 黄球球 | 从守约与居住边界过渡到明确交往，再落到可实现的相处 | 完成最后告别与各自生活；不借变形、消失或公开出游制造结尾 |
| 朋友与职业 | 把清账、重新邀约和新的相聚连接起来，保留各自工作 | 有礼貌的告别与新夜班相接，不用一顿饭恢复如初 |

必须保持：孟遥只有AA秘密继续、婚姻未结束、BA不重启亲密；黄球球入口、形态时点、无手机和门外限制不变；飘自主决定，孩子事务不由文文替毛狼承诺，不新增出生日期/医疗结果/婚姻；朋友线两支均结清工资，FR-E2后日谈只读消息；叶岚没有攻略线。

仍处恋爱、秘密关系或试交往的6类结局直接收束；其余8类按HIGH/LOW和事件条件进入既有后日谈。主线结局应先完成自身的情绪收束，不能依靠飘与毛狼的后日谈替其他人物收尾。

## 四、对白对应立绘，结尾对应CG

### 立绘与表情

- 每个演出段标注在场人物、发言者、交流媒介、情绪变化、衣装、持物、站位与进退场；姓名来源不能从当前立绘反推。
- 复用当前已采用的立绘与差分，先解决说话者错误、出场缺失、表情与台词冲突、换场残留。表达转折才切表情，不要求每句换图；无对应表情时登记缺口，不用持物/衣装错图凑覆盖。
- 听者可留在画面中；电话和群消息保留远程语境。未在现场的人不得用普通现场站姿造成同场误读。
- CG覆盖时继续正确显示姓名；CG结束恢复该分支的背景、人物和道具，不能恢复另一分支的亲密状态。

### CG增补与复核

先做逐结局镜头清单，再制作必要的新图。每镜写明：对应结局和条件、正文稳定锚点、叙事用途、在场人物、时间地点、动作与道具、进入/退出点、复用或新增理由。新图数量由该清单确定，不预先按十四结局各生成一张。

优先考虑三个缺口：关系确认后的自然互动、真正分开时的动作、决定之后的生活回应。飘LOW优先；已有有效收束CG的路线先补前后过渡。回查旧QA中的CG066坐姿/站立偏差，若仍存在则按正文修图，不改正文迁就图片。新增图使用新编号并保留既有解锁记录，不复用已取消编号。

按[美术资源规范](美术资源规范.md)保留源图和历史版本，新增运行图优先WebP，透明立绘保留alpha。扩展CG清单、采用清单、绑定、图鉴容量/分页和固定数量校验，核对完整图与文字框叠加效果。确认文字与镜头后再使用图像工具制作，本轮不生成图片。

**回稿与采用流程：**

1. 中文大模型交付本批完整修订段落，不能用“其余不变”等省略代替正文；附改动原因、说话人/交流媒介、受影响分支、新增信息、未决疑问及可选CG建议。
2. 候选稿存于`docs/修订协作/P2-全稿修订-20261103/正文/`，标明来源版本与“候选定稿／待采用”。独立QA可以复制候选作试编译输入；正式构建唯一正文来源仍是`scenario/`。

4. P3使用新的审读上下文，或另一个用户选定的中文模型，阅读已合并的完整路线及相关共通段，检查人物声音、动机、分手后的边界与结尾节奏；审读意见经总编处理，不能自动覆盖正文。

### 可复制的子任务提示词

**中文大模型路线修订任务（先附齐上述资料包，再替换“目标路线”）：**

> 你负责《毕节，雨停之前》“目标路线”的中文剧情与对白修订。以本次附上的规则、人物资料、路线梗概、原文和模板为依据；这些资料对应的源文件/版本已列在任务包中。先指出本批因果与衔接问题，再交付本批完整修订正文。用对白与可见动作表现人物，保留必要旁白，区分当面、电话、消息与心声，每句明确说话人。保持各人物口吻及信息范围；选择ID、条件、数值、结局结果与已确认事实不得改变。每个结局补齐约2—3段短场景，已有有效收束计入，不能为对白量重复争吵或重启已断开的关系。不得补造婚史、日期、疾病、家庭经历或新关系结果；不能确定时列出问题，不擅自填空。交付完整修订段落、逐项改动理由、影响的分支、新增信息、未决问题及可选CG建议，不省略正文，不输出代码或资源绑定。你提交的是待采用候选，由总编核对合入候选，经过P3冻结与P4演出重绑后再写回scenario；若缺少必要资料，请明确指出。

**中文大模型独立审读任务：**

> 你是本轮独立审读者。阅读所附已合并路线、共通事实、人物资料与分支矩阵，分别检查人物口吻、动机、时间/空间/物品连续性、信息从何得知、分支前后关系，以及结尾是否经过决定、回应和生活落点。不要默认各条件段连续发生，也不要把语言个人偏好当作逻辑错误。按“明确错误／衔接不足／可选润色／需用户决定”列出问题，引用段落标识及原句，解释影响路径并给出最小修订建议。检查此前标记的问题是否已经解决，不直接全稿重写或改变结局。

**编译与姓名任务：**

> 先按本计划设计并验证显式对白格式，保持scenario为唯一正文源，沿用现有Suika3构建链。实现说话人/媒介/正文类型的解析、分页与姓名输出，防止旁白残留姓名，覆盖主角、多人、电话消息、未揭身份、心声与CG覆盖。确认回顾、自动、快进、读档和回退一致。保留控制标记、分支语义、版本校验和玩家旧档，使用新QA批次。先交付小样和模板，供全稿修订任务使用；不批量改路线正文。

**演出与结尾CG任务：**

> 只以合审冻结的正文和当前采用资源为依据，按稳定锚点重建立绘/表情/道具/CG进退场。先交镜头及资源缺口清单，复用合适的现有图，确需新增再制作；明确每图分支条件与远程/现场关系。保护孟遥婚姻与BA限制、黄球球形态、飘HIGH/LOW和单身后日谈门禁。同步图鉴容量、清单、解锁及选项图片变化，保留原图和历史证据；交付逐段映射、图片检查及存读档恢复结果。

## 技能的使用边界

采用[screenwriter](../.agents/skills/rfxlamia-skillkit-screenwriter/SKILL.md)的场景拆分、人物口吻、动作与情绪推进方法；采用[chinese-novelist](/Users/yipin/.cc-switch/skills/skills-echoleesong.chinese-novelist-master-d7f33cf493c39ce31d62acb65b1ca69dccf7e6ed/SKILL.md)的对白、逻辑一致性与润色检查。

本任务是既有分支游戏修订，用户要求“更多对白”和“先写计划”优先：不套用短片“少对白”限制，不重新询问已有题材/人物，不建立另一套`novels/`正文，不强制每章3000—5000字，不把所有结尾改为悬念，也不将整稿强制转成短片XML。CG分镜可另存结构化资料，但剧情唯一来源仍是`scenario/`。
