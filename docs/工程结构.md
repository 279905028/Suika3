# 工程结构

本工程直接使用 `/Users/yipin/Desktop/Suika3`，不再另建 `迁移/Suika3/` 或复制一整套旧项目。

| 路径 | 用途与边界 |
| --- | --- |
| `scenario/` | 唯一可编辑剧情正文、选择设计与路线登记；不放旧稿或生成脚本 |
| `docs/` | 当前人物、分支、开发、美术与CG决策；历史资料用来源链接追溯 |
| `tools/` | 内容检查、`compiler/`正文编译、`runtime/`集成构建和本地运行工具 |
| `qa/<批次>/` | 本轮实际检查及输入指纹；不继承旧通过记录 |
| `SDK/` | 已有SDK、文档及平台工具，锁版本前只读使用 |
| `main.ray`、`start.novel`、`config.ini`、`system/` | 本作宿主入口、配置及GUI源；由`tools/runtime/build.cjs`合并后运行，原SDK入口备份在本批QA |
| `images/`、`sound/`、`suika-beat/` | 已有示例资源与演示；未登记为本作采用资源 |
| `assets/sources/`、`assets/current/`（后续） | 制作原件和批准采用图，按批次建立；不批量复制旧图库 |
| `build/`、`dist/`（后续） | 编译映射和可重建交付物；不得成为第二份手工剧情源 |

不复制旧 `engine.js`、`game.js`、`story.js`、部署凭证、发布包、旧Git和QA库。保留SDK示例使工具环境可追溯，等正式样板通过后按清单替换运行入口。没有新增可运行产物时不创建空架构目录。

来源为原工程当时的未提交最新文件，导入清单含SHA-256，见 [来源记录](../qa/route-merge-20261028/source-manifest.json)。原工程不再作为新版本编辑入口。
