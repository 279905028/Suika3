## 重复打包与验收

输出必须使用新的目录和报告文件，不能覆盖本次包或历史验收。下例中的`新报告.json`和`新目录`需换成新的实际名称。

```sh
node tools/story-revision/p5/verify-final-package.cjs qa/dialogue-p5-motion-20261104/build-v5 qa/新批次/新报告.json
python3 tools/deploy/aliyun/package.py --source-build qa/dialogue-p5-motion-20261104/build-v5 --out dist/新目录 --verification qa/新批次/新报告.json
node tools/deploy/aliyun/verify-web.cjs http://实际地址/ dist/新目录 qa/新批次/外网冒烟
```

网页服务器若启用预压缩文件，须确认已安装相应模块；Nginx的`gzip_static on`按客户端能力选择`.gz`副本，不能把压缩字节直接当原始HTML发送。[Nginx官方说明](https://nginx.org/en/docs/http/ngx_http_gzip_static_module.html)
