# 选项卡 UI 三方案

2026-10-30。范围：剧情选项、路线选择、菜单分类、设置分组、保存/读取切换、回顾与图鉴。本页保留三方案的比较；用户已选定电影侧栏，当前采用与运行说明见[电影侧栏UI](UI-电影侧栏.md)。下方描述为原设计提案，实际布局及验证以采用记录为准。

## 现状与共同改进

依据 `system/sui-u/source/build.py`、SUI-U 六选项历史截图和当前正文。现有剧情按钮为1040×88，六项布局从y=104逐项间隔96，底部到672，覆盖画面中部较多。现有系统页以独立GUI为主，下列分类导航属于新增设计，尚未接入。

- 普通表达的二选项和六路线入口使用同一组件语言，按选项数量改变排布，不对所有选择套用六项布局。
- 路线入口呈现“人物名＋行动”两层信息；行动直接采用 `scenario/第三章-选一条路.md`，不增加好感预告或结局暗示。普通选项保持正文原文。
- 默认、悬停、键盘焦点、按下、不可用分别定义；焦点有可见标记，不能只靠颜色。正式点击沿用现有选择行为，不新增所有选择都要二次确认的流程。演示中的点选仅显示聚焦状态。
- 系统导航统一为设置、存读档、回顾、图鉴；设置内按声音/阅读分组，存读档内用保存/读取切换。返回按钮始终在固定位置，页面切换保留原阅读位置。
- 沿用1自动＋3手动档；保存页自动档只读，覆盖已有手动档时明确槽位。图鉴未解锁时不泄露标题/缩略图；不新增路线筛选以免泄露隐藏内容。
- 黄球球门禁完全沿用当前正文/运行规则，不因展示六按钮而提前开放。预览为已完成前置的六线示意，不是实际存档状态。
- 以1280×720横屏设计；手机继续旋转阅读。下文尺寸为目标设计值，接入时需重新测量文字与触摸区域；手机横屏实际点击区域目标不小于44×44 CSS像素。宽度不足时，优先保留单列，避免把字体等比压得过小。

## 雨夜细线（推荐）

保留青灰、暖白字与浅青色强调。剧情按钮改为较窄的纵向列表，左对齐人物名和行动，焦点用左侧短竖线＋右箭头；分类标签使用文字与下划线，降低框线密度。

- 六路线：目标宽760、每项72高、间隔8，总高472，适合在1280×720中央保留呼吸空间。二选项目标高80、间隔16，长文可换行增高，不能截断。
- 系统页：上方横向分类，声音/阅读为页内分组；存读档用四槽网格与保存/读取分段按钮。
- 状态：默认低对比边线，聚焦时边线加亮并出现位置标记；按下时压深底色，动效约120～160ms，减少动态效果时关闭位移。
- 优点：延续已确认风格，主要改善遮挡、对齐与可读性，接入改动相对最少。
- 取舍：视觉变化克制；仍需新做分类导航及重新校验GUI布局，不能直接沿用旧运行验收。

## 生活手札

暖灰纸面、深褐文字、细线和书签式分类。保留青灰作次要强调，让界面更接近日常生活与纸本阅读。属于较大风格调整，待用户选择后采用。

- 六路线：两列三行卡片，人物名和行动分层；目标每张440×124、横向间隔20、纵向间隔16。顺序按当前正文；二选项仍纵向排列，防止长句互相挤压。
- 系统页：书签标签连接内容页，设置用纸面分组；手动档像记录卡，时间/章节/末句分层，自动档独立标注。
- 状态：焦点用卡片底部深色短线和明确边框，按下时纸面略压深；避免纸纹影响字形。
- 优点：六路线更容易并列扫读，生活气息明显，能与角色日常题材呼应。
- 取舍：亮面会改变雨夜氛围；在亮背景和暗背景上均需重验对比，中文卡片长文的换行成本更高。

## 电影侧栏

深蓝黑底、暖米色细标记，剧情选择集中一侧，给人物和场景保留更大的连续区域。系统页面使用左侧竖向分类与右侧内容。

- 六路线：右侧约480宽的纵向列表，约占画布38%；面板不透明或高遮蔽保证可读，余下区域展示原有画面。二选项在同侧按原文增高，不遮住关键人脸和道具。
- 系统页：左侧固定导航，右侧为存档/设置/回顾/图鉴内容区；图鉴打开后使用独立全图模式。保留文字标签，不把全部导航缩成图标。
- 状态：焦点为暖色竖线、整行底色与箭头；切换内容轻淡入，约160ms，不用大幅横移或循环发光。
- 优点：画面保留最多，剧情选择与人物演出更连贯，适合强调角色表现。
- 取舍：窄列长选项更容易换行，需覆盖全部134个选项；还需按人物/道具所在侧决定避让，原生GUI布局与演出联调成本最高。
