## 并行顺序与状态

1. A01盘点、A09镜头复核可同时开始，各写自己的文档；暂不能决定的设定集中记录并询问用户。
2. 统一规格明确后，A02～A08可按人物/场景并行。同一人物依次完成独立A/B呈现、用户定稿、必要差分；差分是否为某镜头的前置，由A09逐镜列明。用户已确认的事项保留依据，无须重复申请相同确认。
3. 本轮先满足用户要求的全部相关上游定稿与A09全量放行，再开展A10；当前60镜条件已满足。A11滚动检查已完成批次，不跳过人物或条件依赖。
4. A11检查通过且采用获批的文件交SUI-I统一导入。SUI-E/I核对演出绑定，SUI-Q另验引擎加载、CG进入/退出、回退、读档恢复与网页/手机/桌面呈现。

建议状态按实际证据记录：未开始 → 资料齐备 → 待审方案 → 已定稿 → 制作完成 → 格式检查通过 → 待整合；运行验收另记。阻塞时写出所缺依据、影响文件和可继续部分。图片生成、资源检查通过或任务拆分完成均不等于本作可玩。
