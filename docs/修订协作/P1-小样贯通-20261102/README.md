## 三个读取策略

| 策略 | 用途 | 行为 |
| --- | --- | --- |
| `legacy`（默认） | 保留现行未迁移正文 | 按旧格式读取；遇到 TEXT 拒绝，不猜说话人 |
| `mixed` | 本批独立小样 | 验证每条 TEXT；未迁移段继续无姓名读取 |
| `required` | P2/P3 完整迁移后的定稿 | 任一正文缺 TEXT 即拒绝 |

编译可显式传入 `--text-policy`；策略、正文、字段／称呼表与编译器都进入内容版本身份。改变分页或姓名需要新构建，不能把旧档按行号迁移。正式整合仍须新的正文冻结、绑定与选项图片版本核对。
