每包从`templates/P4-02-<包>/`复制四份JSON到自己的`docs/修订协作/P4-演出与美术/P4-02-<包>/`，只编辑自己的副本。不要直接编辑本目录的冻结模板，不把模板的`binding:null`替换为机械复制的旧状态。

草稿检查允许待审与未决项，但仍拒绝缺段、错包、重复、未知资源和条件改写：

```sh
node tools/story-revision/p4-bindings/validate.cjs --package P4-02-COMMON --dir docs/修订协作/P4-演出与美术/P4-02-COMMON --mode draft
```

正式交接检查默认使用`handoff`：逐段、选择、边界均须已审；引用资源须提供本批P4-05复验后的目录；四份JSON之外须有`交接.md`。成功输出每份文件SHA-256、整体输出指纹和覆盖统计，可保存到自己的QA作为回执。

```sh
node tools/story-revision/p4-bindings/validate.cjs --package P4-02-COMMON --dir docs/修订协作/P4-演出与美术/P4-02-COMMON --resources qa/dialogue-p4-P4-05-批次/resources.checked.json
```

工具不写正式绑定、资源或运行入口。条件和规则变化须重新冻结，不能通过编辑包文件绕过；输入或接口字节变化会使检查失败。
