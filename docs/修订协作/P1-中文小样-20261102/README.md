## 二、口吻与改写尺度

1. **拆交流，不扩设定。** 把可对话的转述拆成一位人物的一段发言；动作、必要旁白和文文心声各自保留。不把每句心理活动都说出口，不为了对白占比让人物轮番讲道理。
2. **保留人物差异。** 文文可以自嘲，但不用玩笑消除债务或难堪；毛狼热闹、直接，不能替别人承诺；师匠谈实际安排；飘先讲具体事情再作决定；孟遥能调侃，也会核时间和账，不写成人生导师。
3. **段落服务阅读。** 一段只承担一个叙事动作；说话人、电话与文字消息显式区分。旁白和纯动作清空姓名。对白移除外层引号与重复姓名前缀，但保留必要的句内引用。
4. **结尾写清三件事。** 决定有来由，对方有回应，之后的生活有着落；不把秘密关系写成公开复合，不自动结束婚姻，不把朋友位置写成待机恋爱。
5. **不套通用小说配额。** 本批不采用每章 3000—5000 字、统一悬念结尾或强制情节钩子，也不使用固定手势、套话或“AI 特征词”代替人物反应。字数只做尺度观察，不是通过指标。
