# 选择与解锁规则

当前唯一编号与选项来源为 [选择设计](../../scenario/选择设计.md)，状态与调用说明见[内容契约](../../scenario/规则契约.md)，机器登记见 [routes.json](../../scenario/routes.json)。

第一、二章共通，第15天只选一条路线。五条公开路线可进入；黄球球额外要求C01-02=A、C02-01=A及第14天相识已读。叶岚为普通队友，不能从选线、读档或后日谈进入已取消路线。

各线两关键选择AA进入E1，AB/BA/BB进入E2，保留不同前因；飘LOW单独使用PI-L06-01的两条路径。孟遥AA保持婚姻未结束的秘密关系，其他组合彻底断开；第一次停下后不能靠第二次选A重新开始。

飘好感初始20分，仅C01-06、C02-08、C02-09计分，每处A加10、B减5，不作上下限截断。第14天第三次选择结束后，35分及以上固定为HIGH，其余为LOW；第三章分流沿用该结果，选线和后续选择不重算。其余普通表达选择不计分。

关系初始UNSET，未读齐三个计分节点、缺值或非法值均报错。LOW在第36天读取一次怀孕事件；飘线读自身正文，其他五线按各自调用点读公共事件，再返回调用点之后。结局按高低关系互斥分发后日谈，FR-E2始终保留疏远。当前为内容契约，存档与引擎尚未实现。
