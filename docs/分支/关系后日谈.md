# 后日谈接续

| 已读条件 | 接续 |
| --- | --- |
| HIGH且PI-E1 | 无附加后日谈 |
| HIGH且PI-E2或五条非飘路线结局 | [他们的日子](../../scenario/后日谈-他们的日子.md) |
| LOW、已发生怀孕事件，且已读PI-LE1／PI-LE2或五条非飘路线结局 | [未写完的安排](../../scenario/后日谈-未写完的安排.md) |

两套后日谈互斥，每次只依据刚读到的结局和共通第14天已经固定的关系分发一次；缺失或非法状态报错，不能自动选择默认关系值。MY-E1不因朋友的婚讯变成公开复合或离婚；MY-E2保持断开，不安排复合、私联或恋人式聚会。叶岚无后日谈结局编号。

FR-E2在高、低关系后日谈中均保留疏远，只看群消息与简短回复，不读取私人碰面、现场聚餐或合照，也不自动修复友情。PI-E2高关系保留约半年空档，不能把毛狼写成一直等待两人分手。LOW不预设毛狼与飘结婚；PI-LE1保留文文与飘试着交往，不能同时读取其他低关系结局的伴侣未定段。

详细条件见[内容契约](../../scenario/规则契约.md)与[routes.json](../../scenario/routes.json)。以上为正文接续约定，未完成引擎条件调用与试玩。
