# 飘线

飘20岁，曾在大城市做KTV陪酒，近期回毕节待业，学习摄影并制作街巷册子，喜欢观察拍照与打结。职业学习与个人创作不等于已经就业。

- HIGH：按PI06-01与PI08-01决定PI-E1继续相爱或PI-E2分开；AA为E1，其余组合E2。
- LOW：第36天意外怀孕事件后，PI-L06-01选择继续追求或回到朋友，通向PI-LE1/PI-LE2；A不立即代替飘作出恋爱决定。
- 五条非飘路线按LOW读公共事件，不提供追求飘选项。HIGH的PI-E1不接后日谈，其余HIGH结局接[他们的日子](../../scenario/后日谈-他们的日子.md)；LOW接[未写完的安排](../../scenario/后日谈-未写完的安排.md)，不默认飘与毛狼结婚。

好感初始20分，仅三个共通节点计分：第7天C01-06（照片边界）、第11天C02-08（是否替她决定）、第14天C02-09（具体邀约）；每处A加10、B减5，不作上下限截断。C02-09结束后固定结果：35分及以上为HIGH，其余为LOW。第三章据此分流，选线和后续选择不改分、不重算关系；选飘不自动等于HIGH，选其他线也不自动等于LOW。

关系初始为UNSET。未读齐三个计分节点、缺值或非法值均报错，不能默认LOW。第36天只呈现已经固定的结果：LOW在飘线读自身事件，其他五线读公共事件后返回各自调用点；事件只发生一次，HIGH跳过。

FR-E2无论高低关系都只通过消息与简短回复读取后日谈，不参加现场聚餐，也不自动恢复友情。详细分流、状态与调用规则以[内容契约](../../scenario/规则契约.md)及[routes.json](../../scenario/routes.json)为准；本页不表示已完成引擎、存档或试玩验收。
