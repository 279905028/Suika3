# 六线流程

```mermaid
flowchart TD
  A[第一章：回到毕节] --> B[第二章：十四天]
  B --> R[第14天：三次计分后固定HIGH或LOW]
  R --> C{第15天选线}
  C --> XM[罗小满]
  C --> ZZ[周栀]
  C --> MY[孟遥：前任与已婚现实]
  C --> PI[飘：HIGH或LOW]
  C --> FR[朋友与职业]
  C -->|三拍记录、回应、相识均完成| HQ[黄球球]
  MY --> M{MY07、MY09}
  M -->|AA| ME1[MY-E1：秘密继续]
  M -->|AB、BA、BB| ME2[MY-E2：彻底断开]
```

其余路线及飘分流见 [选择与解锁规则](选择与解锁规则.md)。每条路线独立延续第三至第十章，不能把另一条路线私人事件当作共同前情。关系在共通第14天固定，选线与后续选择不重算；LOW时，飘线读自身第36天事件，非飘五线在各自指定调用点读一次公共事件，再返回该点之后，HIGH跳过。逐线调用与返回锚点见[内容规则契约](../../scenario/规则契约.md)。
