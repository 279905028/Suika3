- 更新六条路线的对白与结尾过渡，共12份、4,748段正文，保留14个结局；关系后日谈只接主结局仍单身的路径。

在 [beta.2 下载页](https://github.com/279905028/Suika3/releases/tag/v1.1.0-beta.2)选择对应附件。

网页包需 Node.js 18或更新版本。解压后双击“启动网页.command”（macOS）或“启动网页.bat”（Windows），也可运行 `node serve.cjs`；用 Chrome 打开 `http://127.0.0.1:49280/`。服务运行期间保持终端窗口打开。端口被占用时先关闭旧版服务，或运行 `node serve.cjs --port 49281` 后打开对应地址。

原生包解压后运行对应平台目录的“启动.command”或“启动.bat”。程序未签名／公证，macOS由系统按常规安全规则处理；存档写在该平台目录的 `save/`，请勿将新版解压覆盖旧版。

**新版从头开始，玩家旧档保留。** 网页存档绑定浏览器、地址、端口和运行构建身份；网页与原生不互通。本包沿用已验运行身份，精确同版本存档可继续；beta.1及其他不同版本档不导入。

## 校验与恢复

`SHA256SUMS.txt`与`checksums.json`校验五份ZIP；`release-manifest.json`关联源码提交、运行身份与附件。GitHub自动生成的 Source code 不含大素材及SDK，不能直接试玩。

开发者解压 build-inputs 后，可运行 `python3 restore-p5.py --out /新的恢复目录`；恢复工具核验原始输入，并按清单恢复网页／原生的预编译阶段。需要重新生成 `assets.arc` 时，加 `--packer /已获系统允许运行的SDK打包器`；工具要求指纹匹配，并核验两端重打包结果。冻结包提供本版实际依赖与派生阶段，不是全部历史原图或素材库备份。

源码位于独立发布分支 `codex/release-v1.1.0-beta.2`，与标签同提交。远端 main 的独立竖屏改动保留，不混入本批已验横屏版本。
