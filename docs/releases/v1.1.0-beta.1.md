# 毕节，雨停之前 v1.1.0-beta.1

2026-10-30｜预览版。六条路线为罗小满、周栀、孟遥、飘、黄球球、朋友与职业；叶岚为普通游戏队友。

本版采用B「夜班灯火」封面，网页标题静音循环播放8秒「损友笑场」；剧情与系统菜单使用电影侧栏。已接入14张普通配角立绘、226项采用资源及60张CG。正文、选择与分支沿用当前版本。

| 附件 | 用途 | 启动方法 |
| --- | --- | --- |

| `v1.1.0-beta.1-macos.zip` | macOS实验包，未完成原生验收 | 解压后运行 `macos/启动.command`；也可在终端进入macos目录运行 `./suika3` |

网页包也提供 `启动网页.command` 和 `启动网页.bat`，两者均需本机已有 Node.js。服务仅监听 `127.0.0.1`，默认端口49280，可用 `node serve.cjs --port 49281` 更换端口。保持终端开启，不要直接双击 `web/index.html`。关闭终端或按Ctrl+C即可停止服务。网页托管未配置，Release是下载入口，不是在线试玩地址。

原生包未签名、公证或制作安装器；若系统阻止打开，请先使用网页包。原生使用静态B封面，不播放网页标题视频。

## 开发者恢复

GitHub自动生成的Source code只含仓库文件，不含大素材和SDK。检出标签 `v1.1.0-beta.1` 后，将构建输入包中 `input/` 的内容按原相对路径合入工程；保留可执行权限。不要用该包覆盖其他开发版本。

以附件 `input-manifest.json` 逐项核对字节数和SHA-256；`candidate-manifest.json`记录原始输入指纹、两端运行身份和产物指纹。构建命令为：

```sh
node tools/integration/runtime/build.cjs --version v1.1.0-beta.1 --snapshot qa/portrait-gap-fill-20261030/snapshot.json
node tools/integration/runtime/verify-package.cjs dist/v1.1.0-beta.1
```

目标 `build/` 和 `dist/` 版本目录必须尚不存在。该流程依赖当前macOS打包工具；归档包含本版冻结输入，不包含全部历史原图、未采用候选或所有QA截图。`SHA256SUMS.txt`／`checksums.json`用于核验Release附件，`release-manifest.json`关联标签提交和构建身份。
