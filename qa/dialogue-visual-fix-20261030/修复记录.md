# 对话立绘与空背景修复

2026-10-30｜网页候选 `sui-i02-20261030-v8`｜本机预览：[127.0.0.1:49244](http://127.0.0.1:49244/)。

## 原因与修改

旧绑定把人物作为单段特写，仅41个节点带人物；下一句会完整重建为空人物列表。另有420个节点没有任何背景、人物、道具或CG，执行器清空背景后显示引擎黑底。旧测试把“下一段隐藏人物”当作通过条件，未覆盖本次要求的连续对话表现。

- 逐文件审读12份正文，登记232条明确在场区间；2,269个节点现在显示对话立绘，修改2,236个节点的人物布局。单人居中、两人分列、三人同框；选择前后保留在场人物，已有单拍表情/动作优先。
- 地点未明确的段落在运行时补现有UI雨窗阅读底图。原420个空画面节点不再清空为黑底；不把电话、群聊或隔门对话擅自放到具体场所。
- 电话、回忆、隔门、离场与跨日不继承人物；黄球球开门许可、球形/人形以及FR-E2后日谈条件保留。
- CG只在原定节点显示；退出、读档、回退均从目标节点重新建立完整背景和人物。

正文、选择条件、路线、60CG时点及212项批准图片字节均未改。新增立绘作为对话肖像，不逐拍重绘坐姿、骑车、剪发等动作；原特写和CG负责具体动作。未制作新图片。
