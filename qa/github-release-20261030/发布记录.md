## 分发与重建

- 四个玩家包：web、macOS通用二进制（x64／ARM64）、Windows x64、Windows ARM64；网页推荐桌面Chrome，后三包标为实验性。附件合计约2.36GB，单附件均小于2GiB。
- 构建输入包包含本版1,341项实际冻结输入及清单，原路径、字节和执行权限保留。它是本次发布版本的恢复材料，不是全部历史原图、未采用稿、SDK示例或QA图片的备份。
- 各包附启动／存档说明、已知问题、引擎官方许可原文和本工程字体许可。没有为本作新增统一开源许可。
- [发布说明](../../docs/releases/v1.1.0-beta.1.md)与[SHA-256清单](SHA256SUMS.txt)随包交付；上传前生成`release-manifest.json`关联源码提交、标签、构建身份和附件指纹。
