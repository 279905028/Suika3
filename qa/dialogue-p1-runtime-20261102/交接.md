## 实现与版本

- 严格校验 TEXT 六字段、已登记称呼、媒介组合、稳定 ID、文件码与分组边界；标记必须紧接一行正文，不能跨导航或结构控制。
- 显式段落使用 `T-文件码-序号`，分页保留原 ID 并附页号和字素偏移。元数据进入中间表示、来源映射和构建版本。
- 具名段输出原生 `text name`；无名段省略 `name`，由引擎隐藏姓名框。姓名独立于立绘；远程段清除现场立绘与道具。
- 保留原 240×48 姓名框图片，按实际最长姓名调整字号。本批使用 20px，完整显示“电话那头的人（电话）”。
- TEXT 默认不混入现行旧稿；`mixed` 仅供独立试验，完整迁移后使用 `required` 拒绝漏标。详情见[格式与下一阶段模板](../../docs/修订协作/P1-小样贯通-20261102/README.md)。
- 本批演出留下 [468 条来源与处理记录](preview-v6/binding-review.json)；六处旧 CG 只放在明确动作上。它们用于小样验证，正式逐段演出仍须 P4 审定。

## 使用与复验

```sh
node tools/runtime/serve.cjs --web qa/dialogue-p1-runtime-20261102/preview-v6/runtime/web --port 49285
```

小样存储前缀为 `bijie-p1-isolated-20261102:`，测试另用临时 Chrome 上下文，未访问玩家日常浏览器或旧档。改字、改姓名或改分页后须新构建并重新开始；保留旧存档，不按行号迁移。

复验工具位于 `tools/story-revision/`：`build-p1.cjs`、`verify-p1.cjs`、`verify-p1-browser.cjs`、`verify-p1-interaction.cjs`、`verify-p1-native.cjs`。构建与测试须传入新的尝试名，已有输出会拒绝覆盖。整合正式正文前还需刷新绑定与选项图片的版本，不能把此小样直接当作正式全稿候选。
