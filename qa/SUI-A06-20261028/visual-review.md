| 对象 | 结果 |
| --- | --- |
| 球形A/B | 保留黄色圆体、深眉、实心圆眼、短红嘴和画面右下托腮手；没有新增人体、衣物、鼻耳或道具；A较光润，B笔触更明显 |
| 人形A/B | 棕发齐刘海、画面右眼白色遮片、米灰外套、印花上衣、黑颈饰和浅色玩偶棒保留；持物手可辨，未补画下装；A袖口左边距较紧，脸与道具未裁切 |
| 透明合成 | 白、黑、浅昼、青灰夜四底均未见大块底色、棋盘格或明显残影；原图透明像素的隐藏RGB不当作可见底色，PNG/WebP全RGBA也另有比较 |
| 横屏UI | 球形等比正方形显示；人形按腰部截幅显示。脸部与关键道具/手部不交正文、姓名和菜单；下身被正文框覆盖属于该静态构图，不改变源图 |

初始UI预览在菜单底图上重复加了MENU，已移除多余测试标记后重新生成。该修正仅涉及QA合成，不修改任何GUI素材。
