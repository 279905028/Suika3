## I02接入要求

使用本页正式快照，先校验再复制固定输入。以下是接续命令，本批仅执行过校验与冻结，没有执行正式构建：

```sh
node tools/integration/runtime/validate.cjs --mode candidate --snapshot qa/sui-i01-closeout-20261030/snapshot.json
node tools/integration/runtime/build.cjs --mode candidate --version sui-i02-20261030-v1 --snapshot qa/sui-i01-closeout-20261030/snapshot.json
```

构建版本名须未占用；新图、正文、绑定或接口变化时另发版本，不修改冻结文件的指纹绕过检查。重新运行I01校验须用 `validate-v2.cjs --out qa/sui-i01-<新批次>`，禁止覆盖本批。

- 每个目标节点按 `enter`完整覆盖背景、人物、形态/衣装、道具与CG；退出按声明恢复，再进入目标节点。选择等待不读取未提交答案，不保留人物/道具/CG；读档和回退须保持当前分支状态。
- CG正文态可能遮挡下方手部或道具，必须保留同段全图查看，隐藏正文、姓名、菜单，且不推进剧情。CG031墙钟及手机细节也须支持全图检查。
- 图鉴登记不解锁，实际显示后才解锁；全局解锁不随回退撤销。离线可达性不等于实际解锁通过。
- 黄球球房间背景中的普通小球为既有道具，不表示角色形态。人物形态以当前绑定为准；不能据背景小球增加球形角色或剧情事实。
