# P4-05 资源检查工具

当前批次始于2026-11-03，2026-11-04交付。只处理离线资源检查，不写正式正文、采用库、演出绑定或运行入口。

- `audit.py prepare`：核对冻结输入并测量245个图像版本，保存本批输入指纹。已有同批结果时拒绝覆盖。
- `audit.py previews`：建立透明图白/黑/昼/夜四底与1:1边缘抽点、横图完整联系表。预览生成不产生目视通过结论。
- `finalize.py`：消费独立填写的`visual-observations.json`，校对覆盖、来源、运行衍生，交资源检查及候选目录。只可在未交付的新批次使用；不把候选制作记录冒作采用批准。
- `verify.cjs`：只读复核原245版本交付，调用P4-01真实检查器验证242项/61CG候选目录与七包draft，结果写入指定的新QA文件。
- `supplement.py prepare/finalize`：另批测量、建立目视表、汇总CG110～129，保留原245版本证据，生成带expanded后缀的完整交接；两个阶段之间必须独立填写目视记录。
- `verify-expanded.cjs`：联合复核265版本/262项候选，实接262项资产及原61项CG编号；另核新增20编号与计划锚点，并明确记录冻结检查器的登记路径依赖。
- `seal.py`：首次交付时核对本包JSON、预览/文档链接、受保护输入及协调文档差异，输出文件指纹与交付检查；已有封存时拒绝覆盖。

复核本次交付：

```sh
node tools/art/p4/verify-expanded.cjs qa/dialogue-p4-P4-05-recheck-YYYYMMDD/verification.json
```

路径必须尚不存在。本工具拒绝覆盖旧复验报告。若要检查后来版本，另建批次，重新测量并重新目视；不能沿用当前文件的检查状态。
