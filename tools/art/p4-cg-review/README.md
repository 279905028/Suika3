# P4-04离线复核工具

工具归属经本包总协调登记在P4-04交接中，只生成本包文档与QA，不改正式游戏。

`build.py`读取人工逐镜判断与P4-01冻结映射，核对576项依赖，解码含返修与新增在内的61项候选原图和运行WebP，制作完整图、文字框预览及七包机器表。`overlay-notes.json`是实际目视后的记录，不由生成器猜测。

本批仍在制作时可运行：

```sh
python3 tools/art/p4-cg-review/build.py
```

本批封存后不重写它；下次复核应在新批次目录运行新版工具。这里的图像输出只是分析预览，不是生成/修图工具或新运行资源。脚本不会调用图像服务。

`verify.py`只读核对独立产物与冻结输入，并向指定的尚不存在的报告文件写回执：

```sh
python3 tools/art/p4-cg-review/verify.py --out qa/新的P4-04复验批次/verification.json
```

需要Pillow；字体和UI均使用工程内文件。不运行引擎，不访问浏览器存储。
