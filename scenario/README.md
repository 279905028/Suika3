## 固定设定

- 文文23岁，失业后从贵阳回毕节。月供3,200，六个月逾期19,200，信用卡另欠8,000；19,200不是全部剩余贷款。第90天房子拍卖，后续款项仍待核清。
- 夜班22:00—06:00，月薪2,000；房租500、信用卡最低600，扣除手机与必要生活支出后约余300。跨城与留宿交代休班；恋爱不偿还债务。
- 第30天回声停业。第60天：小满赴成都学剪烫三个月；周栀与阿英赴贵阳试夜宵摊，陪酒仍是收入来源；孟遥赴贵阳任教；飘计划独自去贵阳学习摄影、继续个人册子，低好感怀孕路径根据身体情况安排。朋友线同日网吧转手、毛狼出发；其他线不默认网吧关闭。叶岚的工作调动仅作配角近况。
- 孟遥已婚，陈晟是有优点、缺点和日常安排的普通人，不靠变坏退出。文文在孟遥路线内得知婚姻，共通线不提前揭露；不擅自增加孩子、家暴、逼婚或婚史日期。
- 小满确实攒过钱并已缴学费，后来动用的是成都生活费。周栀明确从事陪酒，不增加供养者或性交易主线。
- 黄球球自称24岁，无手机、不能公开出现或长留门外。第42天提出尝试人形，第55天17:00自主呈现人形，第60天回屋后仍保持人形；形态不随选择奖励或惩罚。
- 所有亲密人物均为成年人，过程留白。深夜电台是普通节目；不用突然病死、暴富逆袭或强行告白替代关系发展。
