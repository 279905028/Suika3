# SUI-U 本作界面

2026-10-28。用户选定「雨夜青灰」与1280×720横屏优先，手机旋转阅读。此目录是可重建的本作GUI与原生界面辅助代码；根入口仍由SUI-E集成，原SDK示例原件保留。

## 交付内容

| 界面 | 文件与行为 |
| --- | --- |
| 标题 | `gui/title.gui`；开始阅读、继续阅读、设置、图鉴。继续阅读进入四槽读档页；空槽不恢复进度 |
| 正文 | `png/message.png`、`name.png`及配置补丁；30px暖白字、44px行距、三行阅读区、姓名框与下一段标记 |
| 选择 | 1040×88按钮，最多六项；原生悬停反馈；选择时隐藏正文/姓名框，取消SDK旋转与缩放动画 |
| 回顾 | `gui/history.gui`、`history.ray`；原生历史数据、两条阅读区、翻页按钮/页键/拖动条、语音重听 |
| 存读档 | `gui/save.gui`、`load.gui`；slot 0自动档、1/2/3手动档，缩略图、时间、章节、末段文字；保存页不能手动覆盖自动档 |
| 设置 | `gui/config.gui`；音乐/音效/语音、文字速度、自动间隔、文字预览、重置阅读速度与全屏 |

机器可读接口见[integration.json](integration.json)。源文件为[source/build.py](source/build.py)，直接重建本目录，不写根入口、正文或其他任务。`python3 system/sui-u/source/build.py`使用本地Pillow、现有Noto Sans CJK字体及macOS宋体；宋体仅用于静态界面图中的标题，不复制字体文件。PNG/无损WebP的尺寸、编码与指纹见[资源清单](asset-manifest.json)。

## SUI-E / SUI-I 接入

1. 固定原生画布1280×720，应用`config.patch.json`。补丁为配置键替换表；`game.locale`原来被注释，需启用。保留字库授权文件。正式存档身份/数据库由E另冻结，不能沿用本QA身份。
2. 在**构建输出**映射`integration.json`中的五个原生固定GUI路径；对应源均在`system/sui-u/gui/`。不在源目录覆盖原SDK原件。GUI中的`start.novel`必须是本作正式标题入口。
3. Ray无本批已验证的模块导入路径；按`raySourceOrder`合并到E入口，再定义E的`setup/start/update/render`。`Suika.start()`后调用`suiUIStart()`，`Suika.update()`前后分别调用`suiUIUpdate()`、`suiUIAfterUpdate()`，`Suika.render()`后调用`suiUIRender()`。所有剧情状态仍留在Suika变量/脚本位置中。
4. 标题循环提供`sui_title`、`sui_start`、`sui_gallery`三个标签。图鉴标签执行`[sui_gallery]`后跳回`sui_title`；开始标签交给正式正文。正常标题GUI关闭后也跳回标题循环。完整例子只见QA的`native/start.novel`，不要把fixture正文导入正式包。
5. C输出的正文每页不超过三行，溢出继续分页，不缩小字；本批已量测128个A/B选项和六个路线名，正式编译后的转义、最终换行仍须重验。当前SUI-C默认120字素/页，超过本UI约111个全角字的三行容量；E/C须重建，`--page-size 108`可作保守起点，再按真实字体、显式换行与标点复核。不要直接沿用当前3,019页的排版结论。最多六选项，7/8配置仅为引擎保留项，禁止编译器生成超限选项。不要把路线入口的fixture六项当作正式解锁条件。
6. 本批网页壳仅作参考：画布等比完整显示、设备安全边距、竖屏方向提示，canvas使用`touch-action:none`接收游戏手势；触摸回调仍执行原生处理，只在`event.cancelable`为true时取消浏览器默认行为。手机横屏时收起预览工具条，保留错误提示；E需在正式壳上按同一候选重验。浏览器尺寸/触摸模拟不等于物理手机通过。

当前SDK原生音量设置会持久化，文字速度和自动间隔在刷新后会回到0.5。本作辅助代码用原生全局浮点变量`sui_ui_text_speed`、`sui_ui_auto_speed`保存这两项；拖动释放或停止变化180ms后写入，启动后恢复。网页不另存一份设置。`sysbtn.enable=false`用于关闭SDK默认的两阶段系统按钮，本作可见菜单由`suiUIRender()`绘制、`suiUIUpdate()`单击打开；三个界面钩子缺一不可。

回顾页读取`Suika.getHistoryCount/Name/Message/Voice`，按原生“索引0为最新”排列，长条目按38字/行、四行拆分以免裁掉后文；不改写或清空原生历史。当前SDK的`historyscroll`部件未响应，改用Ray绘制分页/拖动。菜单用原生`char`按钮向瞬时变量`sui_ui_action`写H，辅助代码同帧消费并打开回顾GUI，Back/Esc仍由原生GUI返回中断点。该变量属于界面调度，不是剧情选择，也不做全局持久化。

## 图鉴接入约定

`gallery.registry.json`只从`docs/CG当前选择.json`的`activeSelectedIds`建立稳定顺序，不据旧分类冻结制作包；取消的8项不登记。2026-10-29经用户委托补选CG101～CG108，源登记已从52项增至60项，原52项顺序不变；所有`file=null`，没有正式美术被采用。此次仅重执行现有生成器的图鉴登记语句，未重制GUI资源或重建正式运行包，见[补选交接](../../qa/SUI-A09-selection-20261029/交接.md)。原SUI-U的九页运行证据仍属52项历史批次。

集成者逐项使用`suiUIRegisterCG("CG001", "批准的运行资源路径")`注册，返回布尔值；未知编号或不存在文件返回false。注册只绑定图片，不解锁。当前SDK的WebP颜色仍需E解决；GUI与本批图鉴样本用PNG。

正文实际遇到镜头后，由E把对应的`sui_cg_CG001`设为整数1，使用`Suika.makeVariableGlobal({name: "sui_cg_CG001", isGlobal: true})`纳入全局存档，再检查全局保存和浏览器写回。文件已注册与解锁值为1必须同时成立；缺失/0/其他值保持锁定。UI不从结局、路线名或文件名推断解锁。QA的U键只切换一个抽象雨窗样本的标记，正式入口不得带入此调试键或样本绑定。

图鉴在标题页进入；原生自定义tag保持重复执行直至返回。方向键移动焦点、Enter打开，PageUp/PageDown翻页，Esc退出全图/图鉴。已加载页只驻留六个纹理；换页和离开时销毁，不预载全部CG。
